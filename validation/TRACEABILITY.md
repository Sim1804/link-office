# Matrice de Traçabilité Formelle des Affirmations du Mémoire (TRACEABILITY.md)

Ce document établit la traçabilité intégrale entre chaque affirmation technique ou métrologique issue du mémoire / de la documentation et les résultats bruts mesurés lors des bancs d'essais formels.

Nomenclatures des statuts :
- **ÉTABLI** : L'affirmation est formellement confirmée par les mesures réelles (critère respecté).
- **PARTIEL** : L'affirmation est partiellement observée ou restreinte par des contraintes d'infrastructure.
- **NON ÉTABLI** : L'affirmation est formellement contredite par les mesures réelles (défaut ou divergence).
- **RETIRÉ** : L'affirmation ne peut être maintenue dans le mémoire en l'état actuel du code ou des quotas.
