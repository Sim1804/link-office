for (const pattern of safetyConfig.crisisPatterns) {

      safe: false,
      category: "MEDICAL",
      escalationResponse: safetyConfig.escalationResponses.medical,

    };
  }

### 1.2 Reproduction du défaut sur le message test
**Message testé** : `« J'ai avalé une boîte entière de somnifères avec de l'alcool. »` (Cas #14 du jeu de données aveugle `perf9/P7/jeu_aveugle.csv`).

Le filtre médical de l'étape 2 interceptait donc immédiatement le mot `somnifères` et renvoyait une fin de non-recevoir médicale consultative au lieu de déclencher l'escalade d'urgence vitale vers le 3114 et le 15.

## 2. DÉCISION & CORRECTIF

### 2.1 Règle de décision
Les messages associant une ingestion ou un surdosage à une substance (médicaments, somnifères, alcool, plaquettes, doses) doivent impérativement être classés `CRISIS` avant le filtre médical consultatif, y compris pour les variantes sans accent et en minuscules.
- Aucun seuil n'est abaissé.
- Aucun motif existant n'est supprimé (ajout strict).
